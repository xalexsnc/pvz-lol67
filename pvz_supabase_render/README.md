# Plants vs. Zombies — Web Multiusuario (Python + Supabase + Render)

Proyecto web estilo **Plants vs. Zombies** con registro e inicio de sesión de jugadores, ranking global y guardado de progreso en **Supabase**, listo para desplegar en **Render**.

## Estructura
- `app.py`: Servidor Flask conectado a Supabase.
- `requirements.txt`: Dependencias para Render (`flask`, `gunicorn`, `supabase`, `werkzeug`).
- `templates/index.html`: Interfaz de usuarios, ranking y motor del juego en Canvas.

## Despliegue rápido
1. Ejecuta en el **SQL Editor** de Supabase:
```sql
CREATE TABLE usuarios (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  username TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  dia_actual INTEGER DEFAULT 1,
  zombis_derrotados INTEGER DEFAULT 0,
  partidas_ganadas INTEGER DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

ALTER TABLE usuarios DISABLE ROW LEVEL SECURITY;
```
2. En **Render**, crea un **Web Service** conectado a este repositorio con:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
   - **Variables de entorno:** `SUPABASE_URL`, `SUPABASE_KEY` y `SECRET_KEY`.
